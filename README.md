## 📌 Projetos em destaque

### 🎮 Go Warrior!
Jogo 2D de plataforma desenvolvido em **C** com **Allegro 5**, usado como veículo de aprendizado de estruturas de dados.
- Implementa filas, pilhas, listas ligadas e TADs
- Sistema de boss com múltiplas fases, sala secreta, armas e efeitos de partículas
- Sistema de ranking binário usando Quick Sort
- Geração de assets com Pillow

### 🧩 MyLang
Interpretador de uma **linguagem de programação própria**, escrito em C#.
- Arquitetura modular: Lexer, Parser, AST, Resolver, Symbol Table, Interpreter, Emitter
- Testes dedicados para Lexer, Parser e Interpreter

### 🖱️ Jogo Point-and-Click (estilo Monkey Island)
Jogo 2D no estilo *point-and-click*, em desenvolvimento com **C#**.
